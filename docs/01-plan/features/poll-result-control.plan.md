# Plan: 투표 결과 공개 제어 (poll-result-control)

**Date**: 2026-11-21
**Status**: Plan

---

## Executive Summary

| 항목 | 내용 |
|------|------|
| **Problem** | 투표자가 투표 중 결과를 볼 수 있어 편향된 투표가 발생하고, 투표 후 변경/취소가 가능해 신뢰도가 낮음 |
| **Solution** | 투표 중 결과 비공개 + 1회 제출 고정 + 결과 탭 분리 + 마감 후에만 결과 공개 |
| **Function UX Effect** | 투표 탭/결과 탭 분리 UI로 역할이 명확해지고, 마감 전 결과 탭은 🔒 잠금 표시 |
| **Core Value** | 투표의 공정성과 신뢰도 향상 |

## Context Anchor

| 항목 | 내용 |
|------|------|
| **WHY** | 현재 투표 시스템은 결과가 실시간으로 노출되어 후발 투표자가 영향을 받고, 투표 변경/취소가 가능해 신뢰도가 낮음 |
| **WHO** | 투표 생성자(방장), 투표 참여자 |

| **SUCCESS** | 투표 중 결과 비노출, 1회 제출 고정, 마감 후에만 결과 탭 접근 가능 |
| **SCOPE** | PollView 컴포넌트 UI 변경 + 결과 탭 분리, 서버/DB 변경 없음 |

## 1. 요구사항

### 1.1 투표 중 결과 비공개
- 투표자가 아직 투표하지 않은 경우, 결과(득표율/퍼센트)를 보여주지 않음
- "결과만 보기" 버튼 제거

### 1.2 1회 제출 고정
- 투표 제출(저장) 후 "표 바꾸기", "투표 취소" 버튼 제거
- 한 번 제출하면 변경 불가

### 1.3 재입장 처리
- 이미 투표한 사용자가 재입장 시 → 결과 탭으로 자동 이동
- 결과 탭에서 "이미 투표하셨습니다. 결과는 마감 후 확인할 수 있어요." 메시지 표시 (마감 전)

### 1.4 탭 분리 UI
- 투표 페이지를 **투표 탭** / **결과 탭** 2개 탭으로 분리
- 기본 탭: 투표 탭

### 1.5 결과 탭 접근 제어
- 마감 전: 결과 탭이 보이되 🔒 잠금 상태, 클릭 시 "마감 후 공개" 안내
- 마감 후: 결과 탭 열람 가능, 득표수/퍼센트 표시
- 투표 생성자(방장)는 마감 전에도 결과 탭 접근 가능

### 1.6 결과 탭 내용
- 선택지별 득표수, 퍼센트, 막대 그래프
- 총 참여자 수, 총 득표수 표시
- 1위 선택지 강조

## 3. 엣지 케이스

| 상황 | 처리 |
|------|------|
| 쿠키 삭제 후 재방문 | 새 익명 세션 → 재투표 가능 (기존 한계 유지, 미해결) |
| 마감된 투표 첫 방문 | 투표 탭 비활성화 + 결과 탭 자동 활성화 |
| 투표 생성자가 본인 투표 | 방장도 동일한 1회 제출 규칙 적용, 결과 탭은 마감 전 접근 가능 |
| 복수 선택 투표 | 동일하게 1회 제출 고정 |
