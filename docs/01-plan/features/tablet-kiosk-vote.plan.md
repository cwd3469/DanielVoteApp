## 1. 배경 및 목적

현재 투표 시스템은 각 참여자가 스마트폰으로 QR을 스캔해 `/vote/:id`에 접속하는 방식이다.
스마트폰이 없는 참여자는 투표에 참여할 수 없는 접근성 문제가 있다.

태블릿을 공용 투표 기기로 비치해, 한 명씩 직접 선택할 수 있는 키오스크 모드를 추가한다.

---

## 2. 요구사항

### FR-01: 키오스크 라우트
- `/kiosk/:id` 경로로 접근 가능
- 헤더/레이아웃 없음 (전체 화면 집중 UI)
- `/vote/:id`와 완전히 독립된 컴포넌트

### FR-02: 투표 UI
- 투표 제목, 설명(있을 경우) 표시
- 선택지 버튼 — 큰 터치 타깃 (태블릿 손가락 조작 최적화)
- 선택 → "투표하기" 버튼 → Supabase `cast_vote` RPC 호출

### FR-03: 투표 완료 화면
- "수고하셨습니다" 메시지
- 본인이 선택한 항목 표시
- 3초 카운트다운 표시
- 카운트다운 완료 시 선택/상태 초기화 → 다음 사람 대기 화면

### FR-04: 마감 처리
- 투표가 마감된 경우 "마감된 투표입니다" 메시지만 표시 (선택 UI 없음)

### FR-05: 중복 투표
- 1인 1표 제한 없음 (신뢰 기반 운영)
- 매 리셋마다 새 익명 세션으로 투표 가능하게 처리

### NFR-01: 접근 제한
- `/kiosk/:id`는 `/vote/:id`와 동일하게 공개 경로 (admin 인증 불필요)
- `proxy.ts`의 `isPublic` 패턴에 `/kiosk/` 추가

---

## 3. 범위 외 (Out of Scope)

- PIN/코드 기반 1인 1표 제한
- 실시간 득표 현황 표시
- 키오스크 화면 잠금 / 전체화면 강제 API
- 기존 `/vote/:id` 수정
